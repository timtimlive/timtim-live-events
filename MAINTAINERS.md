# Maintainers

| Who | GitHub | Area |
|---|---|---|
| The TimTim.Live team, in the [timtimlive](https://github.com/timtimlive) organization | [@oselo-dotcom](https://github.com/oselo-dotcom) | Everything in this repository |

Every file is owned by `@oselo-dotcom` for now (see [.github/CODEOWNERS](.github/CODEOWNERS)), so every pull request asks for that review. When the organization has a maintainers team, CODEOWNERS moves to it (for example `* @timtimlive/maintainers`).

How decisions are made: [GOVERNANCE.md](GOVERNANCE.md). How to reach us: [SUPPORT.md](SUPPORT.md).

New maintainers are invited by the existing maintainers after a record of good reviews and contributions.
